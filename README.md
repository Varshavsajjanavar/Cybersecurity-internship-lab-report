# Cybersecurity Internship Lab Report

Hands-on security labs from my cybersecurity internship at Agamya Cyber Tech (July - October 2026), documented with screenshots as evidence.

**[Read the full report (PDF)](Cybersecurity-Internship-Lab-Report.pdf)**

## What the report covers

- **Reconnaissance:** host discovery, port and service scanning with Nmap
- **Exploitation lab:** detecting and validating the vsftpd 2.3.4 backdoor on Metasploitable with Metasploit
- **Web application testing (DVWA):** brute force at Low/Medium/High (Burp Suite Intruder, including anti-CSRF token handling), command injection, CSRF, file inclusion, file upload, reflected and stored XSS, phpinfo disclosure
- **OWASP Juice Shop:** 16 challenges, each with the vulnerability class and fix
- **Spoofing labs:** IP/decoy scanning, MAC spoofing, ARP spoofing (isolated lab)
- **Vulnerability scanning:** OpenVAS/GVM setup, scan, and CVSS-scored report
- **Incident report:** PHP2Shell (CVE-2026-109618 / CVE-2026-109619)

## Tools

Kali Linux, Nmap, Metasploit, Burp Suite, Wireshark, OpenVAS/GVM, DVWA, OWASP Juice Shop, macchanger, arpspoof, dsniff

## Disclaimer

All testing was done on my own virtual machines and intentionally vulnerable training targets. No client or real-world systems were tested. For educational purposes only.
